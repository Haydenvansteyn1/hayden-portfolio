# haydenvansteyn portfolio — static site

Plain HTML/CSS/JS, no build step.

- Each page lives at `<route>/index.html` (e.g. `art/paintings/index.html`).
- Images, videos and the résumé are in `media/`.
- Shared scripts/styles are in `assets/`.

## Deploy on Vercel
Import this repo → Framework Preset: **Other** → leave Build Command and Output Directory empty → Deploy.

## Editing text
Open the page's `index.html` on GitHub, click the pencil, search (Ctrl/Cmd+F) for the words you want to change, edit, commit. Vercel redeploys automatically in about 30 seconds.
